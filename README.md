# Queen × Knight: play against the AI

A browser game for the two-player Queen × Knight board game. You play against an AI that uses
alpha–beta search. The site is plain HTML, CSS and JavaScript with no build step and no dependencies.

Live site: after GitHub Pages is enabled, it is at `https://<your-username>.github.io/<repo-name>/`.

## Run locally

Open `index.html` in a browser, or run a local server from this folder:

    python3 -m http.server 8000

then visit http://localhost:8000.

## Run the tests

    npm test

(or run `node tests/test_engine.js` and `node tests/test_ui_smoke.js` separately)

`test_ui_smoke.js` runs the page script against a small DOM stub and plays complete games by clicking the board.

The tests check the JavaScript engine against the Python reference (`engine_reference/`):
400 positions (legal moves, captures, rules), 261 search results (value and move), and a full logged game
that must end with the same score. They also run random and AI-vs-AI games to completion.

## Layout

    index.html                 page and text
    css/style.css              light theme
    js/engine.js               rules, alpha–beta search, AI policy (no DOM)
    js/app.js                  board, controls, game loop
    tests/test_engine.js       Node test suite
    tests/fixtures.json        expected values generated by the Python reference
    engine_reference/          Python engine and the script that writes the fixtures

Regenerate the fixtures after changing the Python reference:

    python3 engine_reference/make_fixtures.py

## Notes

The AI is the AB-4 agent from the project report. Its placement choice is deterministic (the Python version breaks ties at random),
so the AI plays the same way on every run.
